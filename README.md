# Вайрфреймы прототипа Luma

Здесь только макеты: **38 страниц на семь экранов** — все состояния всех экранов продукта.

- `index.html` — обзорный лист: все 38 макетов рядом, клик открывает страницу целиком
- `wireframes/` — сами страницы: панель структуры, переключатель состояний, полоса пути по потоку

**Чего здесь нет.** Ресёрч, персоны с дословными цитатами, бриф продукта, карта сайта,
потоки и журнал дефектов остаются в приватном репозитории. Этот репозиторий существует
только для того, чтобы прототип можно было открыть по ссылке.

**Почему всё серое.** Правило вайрфреймов: цвет появляется на этапе токенов, не раньше.
Серый не даёт спорить о палитре, пока решается структура.

Страницы собраны генератором и не редактируются руками.
